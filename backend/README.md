# LostCats Backend

## Setup

1. Copy environment variables:

```bash
cp .env.example .env
```

2. Install dependencies:

```bash
npm install
```

3. Run Prisma migrations:

```bash
npm run prisma:migrate
```

4. Start the API:

```bash
npm run start:dev
```

The API runs at `http://localhost:3001/api/v1`.
